Crea una aplicación visual completa en un único archivo `index.html`, sin dependencias externas.

Quiero una simulación interactiva de partículas estilo futurista/neón usando únicamente HTML, CSS y JavaScript vanilla.

Requisitos:

- Canvas a pantalla completa.
- Al menos 150 partículas animadas.
- Las partículas deben tener velocidad, dirección, masa y tamaño diferentes.
- Deben rebotar correctamente contra los bordes.
- Deben reaccionar al movimiento del ratón con una fuerza de atracción suave.
- Al hacer clic, debe generarse una onda expansiva que empuje las partículas cercanas.
- Las partículas cercanas entre sí deben conectarse mediante líneas cuya opacidad dependa de la distancia.
- Implementa detección de colisiones entre partículas.
- Añade un sistema simple de física con aceleración, fricción y límite de velocidad.
- Incluye un panel flotante con:
  - FPS actuales
  - número de partículas
  - velocidad media
  - número aproximado de conexiones activas
- Añade controles para modificar en tiempo real:
  - cantidad de partículas
  - fuerza de atracción
  - distancia máxima de conexión
  - velocidad
- Incluye botones para:
  - pausar/reanudar
  - reiniciar la simulación
  - activar/desactivar conexiones
  - activar/desactivar interacción con el ratón
- La interfaz debe tener un diseño oscuro, moderno y tecnológico.
- Debe adaptarse correctamente al tamaño de la ventana.
- Optimiza el código para mantener una animación fluida.
- Usa requestAnimationFrame.
- No uses frameworks, librerías, imágenes ni recursos externos.

Entrega únicamente el contenido completo de `index.html`.

No resumas.
No uses pseudocódigo.
No omitas ninguna implementación.
El archivo debe poder guardarse como `index.html` y ejecutarse directamente en el navegador.
